# 내 영상 편집 워크플로우 — 유학 상담·설명 클립

12강 과제: "내가 원하는 영상 편집 워크플로우 만들어보기".

## 1. 목표
유학 상담·설명 클립(1~3분, 세로 영상)을 올리면, 아래 편집을 **사람 손 없이** 끝내서 돌려준다.
컴퓨터를 꺼 두어도(클라우드) 구글 드라이브에 올리면 결과가 드라이브로 돌아오는 것이 최종 모습이다.

## 2. 편집 항목 (선택한 3가지)
| 순서 | 단계 | 하는 일 | 사용 기술 |
|---|---|---|---|
| 1 | 전사 | 음성을 단어 단위 시간과 함께 글로 바꿈 | faster-whisper |
| 2 | 컷 편집 | 무음, 추임새("어", "음"), 반복어 제거. 긴 무음은 0.3초만 남김 | ffmpeg |
| 3 | 말투 다듬기 | 자막 문장을 정한 말투로 다듬음 (의미·숫자·고유명사는 유지) | Claude API |
| 4 | 자막 | 컷 편집 후 시간에 맞춰 자막 생성, 2줄·한 줄 16자, 영상에 입힘 | ASS + ffmpeg |
| 5 | 최종 렌더 | 위 결과를 한 번에 합쳐 `output/<영상>_edited.mp4` 저장 | ffmpeg |

설명 일러스트, 로고, 개인정보 모자이크는 이 워크플로우에서는 끈다(필요하면 옵션으로 켤 수 있다).

## 3. 실행 방법

### 웹 화면 (내 PC)
`python app.py` → http://127.0.0.1:8766 → 영상 선택 → 옵션에서 **자막 입히기**, **말투 다듬기**만 체크하고 설명 일러스트·로고·모자이크는 해제 → 전체 실행.

### 명령줄 (자동화에 쓰는 형태)
```bash
python autoedit.py 영상.mp4 --tone --subtitles --no-illustrations --no-logos --no-mosaic
```
결과: `output/영상_edited.mp4`. 단계 결과는 `work/` 에 캐시되어, 옵션을 바꿔 다시 돌리면 바뀐 단계부터만 다시 한다.

### 설정 (`.env`)
```
TONE=true
SUBTITLES=true
TONE_STYLE=친근하고 또렷한 존댓말, 군더더기 없이 간결하게
SUBTITLE_POSITION=bottom      # bottom | center | top
SUBTITLE_CHARS=16
ILLUSTRATIONS=false
LOGOS=false
MOSAIC=false
```

## 4. 말투 다듬기 규칙
- 바꾸는 것은 **자막 글자뿐**이다. 음성은 그대로이므로 말한 내용과 자막이 크게 달라지지 않게 한다.
- 의미, 사실, 숫자, 고유명사(학교·지역·제도 이름)는 바꾸지 않는다.
- 문장 길이는 원문 ±20%, 개수와 순서는 그대로 둔다. 규칙을 어긴 문장은 원문을 쓴다.
- 샘플 결과 예: "있습니다" → "있어요", "시작했습니다" → "시작했어요". 음성 인식 오류("유학방남회")도 문맥으로 고쳐졌다. 반대로 "유학레트"처럼 못 고친 것도 있으므로 **게시 전에 자막을 한 번 읽어 본다.**

## 5. 자동화 (드라이브에 올리면 자동)
```
구글 드라이브 '입력' 폴더에 영상 업로드
      ↓
클라우드 Claude Code 세션이 GitHub 의 이 저장소를 받아 실행
      ↓
python autoedit.py <영상> --tone --subtitles --no-illustrations --no-logos --no-mosaic
      ↓
output/*_edited.mp4 를 드라이브 '출력' 폴더에 업로드
```

클라우드 세션에 줄 요청문 예:
> 구글 드라이브 '입력' 폴더에서 아직 처리하지 않은 영상을 내려받아, 이 저장소의 `autoedit.py` 로 `--tone --subtitles --no-illustrations --no-logos --no-mosaic` 편집을 하고, 결과 `output/*_edited.mp4` 를 드라이브 '출력' 폴더에 올려줘. 끝나면 처리한 파일 이름을 알려줘.

### 아직 준비해야 하는 것 (이 저장소에는 없음)
- **드라이브 연결**: 내려받기·올리기를 하는 커넥터 또는 방법. 현재 이 PC 세션에는 구글 드라이브 커넥터가 연결되어 있지 않다.
- **클라우드 환경 설정**: 파이썬 패키지와 ffmpeg 설치, `ANTHROPIC_API_KEY` 를 환경 비밀 값으로 입력 (`docs/cloud-setup.md` 참고). 키는 저장소에 올리지 않는다.
- **자막 글꼴**: 클라우드(리눅스)에는 `Malgun Gothic` 이 없다. 한글 글꼴(예: Noto Sans CJK KR)을 설치하고 `SUBTITLE_FONT`, `SUBTITLE_FONTS_DIR` 를 맞춘다.

## 6. 검증 상태
| 항목 | 상태 |
|---|---|
| 전사 → 컷 → 말투 → 자막 → 렌더 | 샘플 영상(26초) 1건으로 끝까지 확인. 자막 9줄, 말투 수정 반영, 영상에 입혀짐 |
| 컷 편집 효과 | 샘플이 이미 편집된 영상이라 잘린 구간 0개. 무음이 있는 영상으로 다시 확인 필요 |
| 클라우드 실행·드라이브 연동 | **아직 안 해 봄** |
| 한글 글꼴(리눅스) | **아직 안 해 봄** |
| 속도 | GPU 없는 PC 기준 전사 약 38초(26초 영상), 렌더 약 50초 |
